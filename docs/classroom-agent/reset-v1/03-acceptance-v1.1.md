# 课堂 Agent 冻结验收清单 · v1.1（个人单用户版）
冻结日期 2026-11-10。冻结对象为本轮验收标准。初始状态全部为待验，历史报告只用于定位回归样例。

## 版本变更（2026-11-10）
产品决定采用个人单用户模式，本版作为当前验收依据。A1b 真实双用户会话不适用，A1a 测试身份归属回归继续执行。A5 移除真实跨用户场景，保留课时和课程范围验证。A2、A3、A4、A6、A7 沿用原判据。历史判定见 [v1.0](03-acceptance.md)。

## 验收准备
记录代码版本或快照标识、数据库迁移版本、模型与配置。准备本机固定主体、同一课程的两个课时及另一门课程；分别放入可区分的标记词。准备含例题与无例题两段录音、带已知页码的课件、一份旧会议数据副本。预先记录例题、引用页和音频时间区间作为人工核对依据。

|项|操作|冻结通过条件与证据|
|---|---|---|
|□ A1 / R1|创建课程及两个课时，刷新；切换两个课时，核对专属课件与课程共享课件。用测试身份替换复跑归属检查。|归属和数量正确，刷新后专属课件仅在所属课时可见，共享课件在两个课时可见；测试注入另一主体后，直接读写被拒且原内容不变。保存请求结果及前后快照。|
|□ A2 / R2|从页面上传真实录音与课件，点选转写段；模拟一次转写失败后重试。|真实 ASR 产生有序时间段，播放器定位到对应原句，课件可定位原页；失败可见，重试得到一份有效结果。保存作业记录及定位截图。|
|□ A3 / R3|分别处理含例题与无例题的材料，查看规划和各分支输出。|记录选中或跳过的分支；有例题时题干、步骤与原文一致，无例题时无编造题目。逐类抽核一条非空产物及来源。|
|□ A4 / R4|注入失效引用，查看校验结果；用有效草稿发布两次。|失效引用被拦截或修复，确认前草稿不能作为已发布知识召回；重复提交仅产生一份有效发布结果。留存校验记录、版本及索引查询。|
|□ A5 / R5|分别问课件细节、结构化例题、资料外问题和另一个课时的标记词；切换课时与课程范围。|保留两路召回与融合记录、流式响应和点击引用截图。引用对应原文；课时范围排除兄弟课时，课程范围可查该课其他课时，当前课程范围排除其他课程的标记词和材料，资料外问题提示依据不足。|
|□ A6 / R6|分别制造预算不足及供应商超时，检查运行详情后恢复服务重试。|预算阻止超额调用；重试次数符合配置，终态可见，可查分支耗时、错误与用量，恢复后无重复产物。留存配置与调用记录。|
|□ A7 / R7|对旧库副本执行迁移，与迁移前按标识比对；从默认首页走完上传至引用回跳。|旧记录数量、内容和归属可核对，无隐式归课；用户全程可经课堂页面完成任务。保存迁移对照与浏览器操作记录。|

## 判定与变更
每项登记执行人、日期、快照、证据路径及通过／失败／阻塞。任何一项失败或缺少证据，整体验收保持未通过。真实供应商不可用时登记阻塞。修改判据须另发版本，列明受影响编号并重新执行相关项。
