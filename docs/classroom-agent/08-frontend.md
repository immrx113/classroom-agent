## 课时工作台

桌面采用资料列表、阅读区与问答区的可调整布局；小屏通过标签切换。播放器只保留一个共享实例，切换转写/笔记不重置播放位置。

- 音频区域：真实时长、播放速度、定位、上传/录音状态。
- 转写区域：说话人、时间、搜索、纠错和版本提示。
- 笔记区域：章节大纲、关键结论、引用、编辑与发布。
- 知识点/例题区域：结构化展开和原文定位。
- 任务状态：上传、排队、转写、整理、索引分别显示；可处理失败块和任务重试。

处理百分比只在有明确总量的阶段显示；ASR 排队或供应商未知进度显示阶段状态，不编造整体进度或 ETA。

## 引用与播放器联动

统一 `EvidenceLink` 组件：点击引用 → 请求授权证据 → 打开相应课时与来源版本 → 音频元数据加载完后 seek → 高亮转写片段 → 虚拟列表滚动到片段。

同课时直接定位；跨课时先切换来源并显示标题，保留返回问答入口。无时间戳的来源只定位文本，不伪造秒数。旧证据标记“来自历史版本”，文档来源定位页码或段落。

支持复制带 evidence_id 的站内定位链接；访问者仍需通过权限校验，不把复制链接当公开授权。

## 状态与接口衔接

- Query key 包含主体上下文、course_id、lecture_id、source_version；切换课程不会复用错误缓存。
- 上传后使用返回 job_id 跟踪阶段；轮询采用退避，任务完成后刷新相关版本，卸载页面停止轮询。
- SSE 草稿与最终答案区分，断流查询消息终态；正在生成时明确取消与重试行为。
- “当前课时/整门课程”在发送前可见；历史消息保留发送时范围。
- 录音权限拒绝、索引构建中、无答案、服务故障和空课程各有对应提示和可执行入口。
- Markdown 禁止任意 HTML 注入；引用通过结构化组件渲染，不把模型输出 URL 直接当可信内部操作。

## 验收

- 点击笔记或答案引用，能定位正确音频版本和片段；列表虚拟化不影响高亮与跳转。
- 页面刷新保留任务和已保存答案；切课程后不显示前一课程的缓存片段。
- 键盘可操作播放、引用、标签和对话输入；小屏能完成上传、阅读和问答。
- 长转写和长聊天保持可用，性能结论基于指定样本与设备记录，不用未实测的“千条流畅”描述。
