## 证据边界

本方案基于静态代码核查，不代表真实外部服务或部署已验证。此前核查文档记录的决策冒烟脚本通过结果只覆盖当时的离线样本，不可外推为新课堂功能已通过验证。本次没有重新执行这些脚本。

## 建议实施批次

| 批次 | 主要改动 | 必须形成的可验收行为 |
| --- | --- | --- |
| 1 数据基础 | 课程、主体范围、音频/转写版本、证据 schema、迁移 | 新旧数据库可迁移，跨用户访问拒绝 |
| 2 可靠输入 | 安全上传、实际格式/时长、真实 ASR 失败状态、任务/outbox | 重启可恢复，不自动写入 Mock |
| 3 全课整理 | 分块清单、章节笔记、来源引用、原子发布 | 长录音末尾内容可核对且可回听 |
| 4 检索闭环 | 原文与课件索引、版本切换、课程过滤 | 同名课程/文件不混用、不误删 |
| 5 学习问答 | 工具与有限循环、引用校验、SSE 终态 | 回答有可核对证据，断流状态一致 |
| 6 学习工作台 | 新导航、课时页面、播放器联动 | 学生能完成完整录音问答流程 |
| 7 扩展功能 | 直接录音、知识点/例题完善、练习判分 | 分片可恢复，作答反馈可追溯 |

工作台基础页面随批次 1—5 同步提供，批次 6 完成整体验收，不把所有前端工作拖到最后。

## 数据迁移步骤

1. 在测试副本检查 Alembic 链、vector 扩展、表字段、外键和索引；修复 `transcription_mode` 等模型与迁移差异。
2. 备份数据库与音频资产并验证可恢复；记录旧记录数量与资产清单。
3. 采用“新增结构 → 回填 → 双读兼容 → 新写切换 → 停旧写 → 后续清理”的扩展收缩方式，不直接破坏性重命名全部表。
4. 创建历史课程和 ID 映射，将会议原数据标记为历史资料。Mock、未知来源与真实录音分别标记；未知来源不冒充真实课堂。
5. 回填转写版本与时间单位，校验旧数据缺少音频、时间为空、片段乱序等情况；异常项列入待处理报告。
6. 重建课堂索引，检查有效版本与范围过滤，再切换新页面和问答路由。
7. 保留至少一个发布周期的旧接口只读兼容层和归档入口；实际停止日期在上线计划中明确，不由本方案假定。

不把课堂知识点自动回填成旧决策，也不把旧风险自动回填成学生薄弱点。

## 回退与发布

- 功能开关分别控制新上传、课堂处理、新检索、新问答和练习。
- 发布异常先关闭新任务接收，保留已完成版本与只读查询；停止有问题的 worker，修复后从阶段任务恢复。
- 回退应用时确认旧版本是否能读取新增字段和资产；有新结构写入后，不直接运行会删除数据的 downgrade。
- 删除使用业务不可见标记与异步清理任务，物理删除前保留约定恢复窗口；清理任务同样需要幂等与审计。
- README、环境变量样例、Compose/worker 启动说明和 API 文档跟随功能更新。移除未经实现的全量扫描、审批、断点恢复和效果指标描述。

## 验证矩阵

| 范围 | 样本/故障 | 检查内容 |
| --- | --- | --- |
| 迁移 | 空库、旧数据副本、重复执行 | 字段齐全、数量一致、无孤儿引用、可恢复 |
| 范围隔离 | 两用户、两课程、同名资料 | CRUD、检索、媒体、证据、工具、缓存均不越界 |
| 上传 | 超限、特殊文件名、伪造音频、中断 | 无越目录写入、无完整资产误发布、内存可控 |
| ASR | 限流、超时、静音、专业术语 | 真实失败可见、无 Mock 污染、任务可恢复 |
| 长文本 | 人工放置开头/中部/末尾知识点、跨块例题 | 全量核心片段覆盖，输出不重复、不截断 |
| 证据 | 无效 ID、旧版本、缺时间、错误引用 | 拒绝无效引用，版本提示和回听正确 |
| 检索 | 中文术语、同义词、同名概念、无答案 | 标注证据 Recall@K/MRR、最终引用质量 |
| Agent | 工具越权、材料提示注入、循环无收敛 | 参数验证、范围不扩大、次数与预算生效 |
| 可靠性 | worker 退出、重复投递、任务取消 | 无重复产物，恢复和成本记录正确 |
| SSE | 断网、刷新、重复发送、主动取消 | 消息幂等、草稿/终态一致、引用可恢复 |
| 练习 | 歧义题、错误答案、评分故障 | 隐藏答案、评分依据、待确认与反馈可用 |

这些测试针对数据丢失、错误引用、越权、成本和恢复等关键行为。纯文案、样式和简单布局调整以人工检查或现有构建检查为主，不增加仅镜像实现的测试。

## 评估数据与报告口径

建立经授权或脱敏的课堂样本集，每段包含音频、人工转写片段、知识点和证据标注。固定训练/调参样本与验收样本边界，避免只在演示例子上调参。

- ASR：分别记录文字错误、术语错误、说话人和时间偏差。
- 抽取：分别记录 Schema 合法率、知识点覆盖、事实正确、证据支持；空数组不默认计为成功。
- 检索：记录标注证据排名、Recall@K/MRR、候选来源、参数和索引版本。
- 问答：记录结论支持、引用定位、范围正确和证据不足时的行为。
- 稳定性：记录重试次数、恢复点、重复产物和失败终态。
- 性能/成本：记录音频时长、文本长度、设备、并发、队列等待、处理耗时、首段响应和真实/估算费用。

完整片段清单覆盖、有效证据引用、访问隔离、重跑幂等和失败可见作为功能门槛；准确率、延迟和预算的数值目标在基线测量后单独确定并写入验收报告，不能把设计目标当实测结果。

## 首版完成定义

一门课程内，用户可以上传真实课堂录音，得到完整转写和可编辑笔记；关键结论能回到原文与录音；学习问答只使用允许范围并给出有效引用；材料不足与任务失败能明确显示；重启或重试不会重复写出产物或覆盖新版本。直接录音和复习调度按独立阶段验收。
